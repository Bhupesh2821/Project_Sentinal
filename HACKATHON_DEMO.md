# SENTINAL V0.3 hackathon demonstration — November 4, 2026

Use actual model outputs and describe every observation as possible. The demo is a prototype; missed detections and false positives remain. The included silent moving-weapon clip is public-domain range footage; it does not involve opening a camera or handling a weapon.

1. Double-click `web.command`. On first launch choose your local administrator username/password. Sign in at `http://127.0.0.1:8765/app`. Empty state is expected before delivery; it is not a safety guarantee.
2. Double-click `demo.command`. This selects the genuine moving range video and the explicit weapon demonstration profile (score0.35, persistence0.3s, maximum gap2s). Capture still waits for Start. Do not enable evidence, recording or sound unless deliberately wanted.
3. Open **Connected command center…**, load `config/connected/edge-credentials.json`, and enable outbound metadata. The dialog reports actual queue/delivery counts. Press **Start** in the desktop window.
4. Show the actual possible-weapon box, score and timestamp. Wait for temporal confirmation; show the possible alert reaching the browser. No detection is hardcoded. If this selected clip produces no alert, report the failure and inspect the diagnostics rather than inserting an incident.
5. In the private browser, inspect model/version, category, box and source. Acknowledge, then dismiss after review; show its audit. A second signed-in browser session sees the stored decision. Viewer accounts cannot review.
6. Stop the desktop monitor. Show inactive camera/engine health. Load `data/v02-demo/fire_repeated_still.mp4` or `smoke_repeated_still.mp4`; enable fire/smoke in Operator center and use the documented demonstration profile. These files repeat genuine licensed photographs: call them integration examples, not natural-motion fire/smoke validation. Default alert score0.60 missed these positives in the previous quality screen; lowering a demo threshold does not validate reliability.
7. For the hosted route, sign in through Base44 and load `config/connected/base44-edge.json`, the separate Base44 pairing, instead of the local one. Cloud delivery carries metadata only; the hosted Live page does not stream private CCTV. Use only the verified published links in the verification report. Do not expose the local service publicly.
8. Show the public site at desktop and mobile widths, current persisted incident status and runtime diagnostics. Layout emulation does not establish physical iPhone/Android/Windows acceptance.
9. Stop monitoring, disable outbound delivery and close the desktop. Stop the local service with Control+C. An in-flight metadata request may finish within its bounded timeout. Camera images/audio are not recorded by this sequence.

For live input select the exact Mac/iPhone identity or an authorized saved ONVIF/RTSP source before Start. An unavailable identity never silently switches cameras. The nearby CCTV list shows compatible ONVIF advertisements on an explicitly selected interface, not every Wi-Fi device. Physical CCTV/iPhone acceptance remains separate from loopback integration.
