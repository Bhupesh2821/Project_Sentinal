# SENTINAL 0.1.2 — Explicit cameras and network CCTV

Delivered 2026-10-29, MARK-007 Vision Core.

- Select the exact Mac, iPhone or external camera. Device ordering no longer chooses another camera; missing devices fail clearly.
- Find compatible ONVIF cameras on the local network, request profiles with in-memory credentials, and explicitly Start the selected stream. Direct RTSP/HTTP input remains available.
- Browse 577 permitted categories in optional lightweight/higher-capacity Open Images models, including 16 safety/tool labels. This mode is experimental: actual helmet/ladder examples succeeded, but many sampled tools were missed.
- Keep dynamic imports, pause/seek, tracking, real performance reporting and optional sampled SQLite. Session metadata now records model provenance with a migration for existing databases.

Verification and field gaps: see VERIFICATION_REPORT.md and dated raw evidence. Physical CCTV and dependable PPE recognition are not claimed. All files remain in the canonical Project Sentinal folder.

# SENTINAL 0.1.1 — Dynamic video and live inputs

Released implementation: 2026-10-27, MARK-007 Vision Core.

- Import or drop new videos while the app is running, with local managed storage, progress/cancel and duplicate protection.
- Switch sources without reloading model weights; pause, seek and resume local videos.
- Use the Mac camera or enter a compatible network-camera endpoint with in-memory credentials.
- Process recent live frames through an isolated capture process, report skipped frames/analysis age, and reconnect interrupted network feeds with fresh track sessions.
- Preserve optional local metadata recording and existing detection/overlay/statistics controls.

Verification: 203 automated tests, 52 native dynamic-input/network checks, 35 native file/metadata regression checks, 98 native camera checks, and a 60-second actual camera observation. Warm camera processing measured23.99FPS with17.11ms meanvision latency on this Mac's MPS backend. Measurements are observations, not fixed hardware promises.

Physical IP-camera compatibility requires the actual endpoint. Codec/scene-dependent detection misses, occlusion/ID changes and longer field operation remain limitations. No V0.2 BAGWATCH or unsupported event-intelligence feature is included.
