# SENTINAL V0.2.0 — Hackathon prototype

Extends V0.1.2 with pinned, restricted-load specialized weapon/fire/smoke inference, independent specialized overlays and model health, temporal candidate/alert assessment, local opt-in sound/desktop output, owner-local incident history/evidence and audited operator review. The existing Mac/iPhone selection, dynamic videos, ONVIF/network feeds, ordinary object models, tracking and optional metadata remain in place.

The Operator center adds camera health, incident filters/review, AI rules and measured diagnostics. The demonstration launcher selects licensed recorded input and explicit prototype thresholds without hardcoding predictions. Exact model sources/classes/license scope and accuracy limitations are recorded in the model manifest and verification report.

Camera credentials can be saved explicitly in macOS Keychain; session-only is default. Stream recovery uses bounded backoff. Recording, evidence, sound and desktop output start off. No external recipient, emergency service, facial identity or criminal-intent inference is implemented.

GHS recognition, remote notifications, configurable frame-queue depth, ONNX/Core ML execution and production safety certification remain outside the completed prototype. Evaluation is small and selected; misses and false positives remain. V0.2.0 is a versioned prototype, not a claim of complete field acceptance. Read `VERIFICATION_REPORT.md` before presenting.
